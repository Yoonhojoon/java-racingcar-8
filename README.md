# java-racingcar-precourse

## ⚙️ 구현할 기능 목록

### 🚘 입력 관련

- [ ]  사용자로부터 경주할 자동차 이름을 입력받는다.
- [ ]  자동차 이름이 1~5자 이내인지 검증한다. (유효하지 않으면 예외 발생)
- [ ]  사용자로부터 시도 횟수를 입력받는다.
- [ ]  시도 횟수가 1 이상의 정수인지 검증한다.

### 🏁 자동차 경주 로직

- [ ]  각 자동차는 0~9 사이의 난수를 받아 4 이상일 경우 전진한다.
- [ ]  경주를 지정된 횟수만큼 반복 실행한다.
- [ ]  매 시도마다 모든 자동차의 현재 위치를 출력한다.
- [ ]  모든 경주가 끝나면 최종 우승자를 계산한다.
- [ ]  우승자가 여러 명일 경우 쉼표(,)로 구분하여 출력한다.

### 🧱 도메인 객체 설계

- [ ]  `Car`: 이름과 위치를 관리하며, 전진할 수 있다.
- [ ]  `RacingGame`: 경주를 진행하고 결과를 관리한다.
- [ ]  `MoveRule`: 전진 조건을 판단하는 규칙 인터페이스를 정의한다.

### 🧪 테스트 항목

- [ ]  이름과 횟수 입력 유효성 테스트
- [ ]  난수 조건(4 이상일 때 전진) 테스트
- [ ]  여러 라운드 진행 시 위치 누적 테스트
- [ ]  최종 우승자 판별 테스트
- [ ]  통합 시나리오 테스트 (입력 → 실행 → 결과 출력)
